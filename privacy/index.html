このツールについて

Dashboard は、開発者本人が自分の iOS アプリの状況（ダウンロード数、評価、広告収益など）を確認するための個人用ツールです。一般の利用者向けには提供していません。

取得する情報

  • Google アカウントでの許可（OAuth）を通じて、開発者本人の AdMob アカウントのレポート（推定収益、表示回数、クリック数、広告リクエスト数、アプリ一覧）を読み取り専用で取得します。
  • 要求する権限は https://www.googleapis.com/auth/admob.readonly のみです。広告の設定変更や、その他の Google のデータへのアクセスは行いません。

利用目的

取得した情報は、開発者本人がアプリの収益状況を確認するためだけに使います。広告配信、第三者への提供、販売には使いません。

保存と管理

  • 集計結果は、開発者本人の非公開の GitHub リポジトリに保存します。
  • スマートフォン向けの表示用ページは暗号化して公開しており、パスワードを知っている開発者本人だけが閲覧できます。
  • 認証情報（リフレッシュトークン等）は GitHub の暗号化された Secrets に保存し、公開しません。

第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供することはありません。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもこのツールへのアクセス許可を取り消せます。

Google API サービスのユーザーデータに関するポリシー

Google API から取得した情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
